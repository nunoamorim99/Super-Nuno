# Super Nuno 🍼➡️❤️

Super Nuno is an autobiographical Mario-style 2D platformer. Five worlds tell five life
stages — Nuno grows **baby → kid → teen → adult → love** as you progress. Built with
Phaser 3 and Vite (vanilla JS), playable on desktop and mobile from the same URL, and
deployed to GitHub Pages.

**▶ Play it live:** https://nunoamorim99.github.io/Super-Nuno/

## Run locally

```bash
npm install
npm run dev      # dev server
npm run build    # production build → dist/
npm run preview  # serve the production build locally
```

On Windows PowerShell, use `npm.cmd` if script execution is restricted.

## Lineage

Super Nuno evolves **[AstroHop](https://github.com/nunoamorim99/AstroHop)** (MIT), a
working Phaser 3 platformer whose engine, feel, and deploy pipeline this project keeps
and builds the story layer on top of. All art is edited [Kenney](https://kenney.nl)
CC0 — no AI-generated art.
